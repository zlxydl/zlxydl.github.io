# docker部署项目全流程

```
代码完成
  ↓
编写 Dockerfile
  ↓
构建镜像（docker build）
  ↓
本地验证容器（docker run）
  ↓
推送镜像到仓库（Docker Hub / 私有仓库）
  ↓
服务器拉取镜像
  ↓
使用 docker run / docker compose 启动
  ↓
配置反向代理 & 端口暴露
  ↓
日志、数据卷、重启策略
  ↓
上线 + 回滚预案
```
